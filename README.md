# 오늘 관제판 (daily-dashboard)

최태열 대표님용 모바일 데일리 대시보드. 정적 앱 두 파일: `index.html` + `data.json`.

- 아이폰 사파리에서 열고 **공유 → 홈 화면에 추가**로 앱처럼 사용
- 화면을 열 때마다 `./data.json?t=…` 를 새로 받아 그립니다(캐시 무시). 네트워크 실패 시 `index.html` 안의 내장 fallback 데이터로 그대로 동작합니다.
- 오늘의 발행 미션 체크 + 진행률 (날짜 기준 자동 저장/다음 날 초기화)
- 미션마다 **[📋 문안 복사]**(원터치 클립보드 + 토스트)와 **[열기 ↗]**(해당 앱 새 창)
- 상단 **브리핑 배너**(`briefing` + `updated_at`, ↻ 버튼으로 즉시 재동기화)
- 핵심 체크 3건 (탭해서 확인)
- **작업실 바로가기** 2×2 그리드 (슬랙·미리캔버스·쿠팡 WING·유튜브 스튜디오)
- 집중 타이머 25/10/5분, 시작·일시정지·리셋, 종료 시 Web Audio 차임
- 날씨는 Open-Meteo(대구)에서 읽어오고 실패 시 지역명만 표시

## data.json 계약 (매일 자동 갱신용)

```json
{
  "date_label": "11월 16일 월요일",
  "updated_at": "17:10 기준",
  "briefing": "한 줄 브리핑 문장",
  "missions": [
    { "id": "m1", "title": "🧵 스레드 점심 공감", "time": "12:00",
      "app_label": "스레드", "app_url": "https://www.threads.com/", "copy_text": "복사할 문안" }
  ],
  "checks":   [ { "id": "c1", "emoji": "🛒", "label": "항목", "tag": "상태", "tone": "red|amber|green|blue" } ],
  "shortcuts":[ { "id": "s1", "label": "💬 슬랙", "url": "https://…" } ]
}
```

- `missions` 가 화면의 미션 목록ㆍ진행률 기준입니다. `id` 는 체크 상태 저장 키이므로 회차가 바뀌어도 되도록 같은 의미면 같은 id를 쓰고, 새 미션이면 새 id를 씁니다.
- `copy_text` 가 빈 문자열이면 [문안 복사] 버튼이 숨겨집니다(대령 후 채우면 자동 반영).
- `date_label` 은 오늘 날짜와 일치할 때만 배지에 쓰이고, 아니면 실제 오늘 날짜를 계산해 표시합니다.
- 체크 상태는 브라우저 localStorage(`today-board.v1`)에 날짜 기준으로 저장됩니다.

## 프라이버시

공개 저장소입니다. 제3자 실명·연락처·상세 주소·계정 핸들·민감 사업 정보는 넣지 않습니다. 미션 문안은 본인 발행 원고만 담습니다.
