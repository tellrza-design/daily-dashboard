# 오늘 관제판 (daily-dashboard)

최태열 대표님용 모바일 데일리 대시보드. 정적 앱 두 파일: `index.html` + `data.json`.

- 아이폰 사파리에서 열고 **공유 → 홈 화면에 추가**로 앱처럼 사용
- 화면을 열 때마다 `./data.json?t=…` 를 새로 받아 그립니다(캐시 무시). 네트워크 실패 시 `index.html` 안의 내장 fallback 데이터로 그대로 동작합니다.
- 오늘의 발행 미션 체크 + 진행률 (날짜 기준 자동 저장/다음 날 초기화)
- 미션마다 **[📋 문안 복사]**(원터치 클립보드 + 토스트)와 **[열기 ↗]**(해당 앱 새 창)
- **🧵 스레드 소통 10초 컷** — 주제 라벨 + [글 열기 ↗] + [답글 복사]. **2개씩 한 세트**, 카드 우측 상단에 `1 / 3세트` 표시와 **[다음 2개]** 버튼(서버 통신 없이 즉시 다음 세트). 세트 위치는 날짜별 localStorage에 저장
  - 마지막 세트에서 **[다음 2개]**를 누르면 `준비된 6건을 모두 확인했어요` 안내와 **[새 글 요청 복사]**("스레드 소통 새 글 6개 채워서 대시보드에 올려줘" 클립보드 + 토스트), **[처음으로]** 미니 버튼이 나옵니다
  - 복사하면 자동 완료 체크(수동 토글 가능, 날짜별 저장)
- **🍳 오늘의 10분 식단** — 1줄 아코디언, 탭하면 원팬 레시피 단계가 펼쳐짐
- **📊 4대 채널 · 이커머스 미니 현황판** — 라벨·값 + `progress`가 있을 때만 진행률 바
- 상단 **브리핑 배너**(`briefing` + `updated_at`, ↻ 버튼으로 즉시 재동기화)
- 핵심 체크 3건 (탭해서 확인)
- **작업실 바로가기** 2×2 그리드 (슬랙·미리캔버스·쿠팡 WING·유튜브 스튜디오)
- 집중 타이머 25/10/5분, 시작·일시정지·리셋, 종료 시 Web Audio 차임
- 날씨는 Open-Meteo(대구)에서 읽어오고 실패 시 지역명만 표시

## data.json 계약 (매일 자동 갱신용)

```json
{
  "date_label": "11월 16일 월요일",
  "updated_at": "17:10 기준",
  "briefing": "한 줄 브리핑 문장",
  "missions": [
    { "id": "m1", "title": "🧵 스레드 점심 공감", "time": "12:00",
      "app_label": "스레드", "app_url": "https://www.threads.com/", "copy_text": "복사할 문안" }
  ],
  "threads_replies": [
    { "id": "tr1", "topic": "인사·마음챙김", "url": "https://www.threads.com/@…/post/…",
      "reply_text": "붙여넣을 답글 문안" }
  ],
  "dinner": {
    "menu": "18:30 저녁 메뉴 브리핑 대기", "prep_time": "10분 컷",
    "steps": ["1단계", "2단계", "3단계"]
  },
  "status_board": [
    { "label": "🪷 연꽃세상 수익창출", "value": "1,887 / 4,000h", "progress": 47 },
    { "label": "🛒 모모상점 재고", "value": "품절 1건 확인", "tone": "red" }
  ],
  "checks":   [ { "id": "c1", "emoji": "🛒", "label": "항목", "tag": "상태", "tone": "red|amber|green|blue" } ],
  "shortcuts":[ { "id": "s1", "label": "💬 슬랙", "url": "https://…" } ]
}
```

- `missions` 가 화면의 미션 목록ㆍ진행률 기준입니다. `id` 는 체크 상태 저장 키이므로 회차가 바뀌어도 되도록 같은 의미면 같은 id를 쓰고, 새 미션이면 새 id를 씁니다.
- `copy_text` 가 빈 문자열이면 [문안 복사] 버튼이 숨겨집니다(대령 후 채우면 자동 반영).
- `threads_replies` — `topic` 이 화면에 보이는 유일한 문구입니다(계정 핸들은 UI에 표시하지 않고 `url` 로만 연결). `reply_text` 는 [답글 복사] 로 클립보드에 들어가며, 복사 시 자동 완료 처리됩니다. 빈 배열이면 카드가 숨겨집니다.
  - 배열은 **2개씩 묶어 3세트**로 보입니다(6건 기준 `tr1`~`tr6`). 6건이 아닌 개수여도 2개 단위로 세트가 자동 계산됩니다(예: 4건이면 2세트, 홀수면 마지막 세트가 1건).
- `dinner` — `steps` 가 1·2·3 번호 목록으로 펼쳐집니다(3줄 권장). `prep_time` 은 배지 문구(없으면 배지 숨김). `dinner` 가 없으면 카드가 숨겨집니다.
- `status_board` — `progress`(0~100)가 있는 행만 진행률 바가 그려지고, 없는 행은 `tone` 색 배지로 값이 표시됩니다. 빈 배열이면 카드가 숨겨집니다.
- `date_label` 은 오늘 날짜와 일치할 때만 배지에 쓰이고, 아니면 실제 오늘 날짜를 계산해 표시합니다.
- 체크 상태는 브라우저 localStorage(`today-board.v1`)에 날짜 기준으로 저장됩니다(`done`·`checks`·`replies`·`replySet`).

## 프라이버시

공개 저장소입니다. 제3자 실명·연락처·상세 주소·계정 핸들·민감 사업 정보는 넣지 않습니다. 미션 문안은 본인 발행 원고만 담습니다.

예외 하나: `threads_replies[].url` 은 답글을 달 원글의 공개 링크라서 경로에 원작성자 핸들이 들어갑니다. 화면에는 `topic` 문구만 보이고 핸들은 표시하지 않으며, 이 링크가 유일하게 핸들이 남는 자리입니다.
