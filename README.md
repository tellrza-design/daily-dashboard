# 오늘 관제판 (daily-dashboard)

최태열 대표님용 모바일 데일리 대시보드 V2. 정적 앱 두 파일: `index.html` + `data.json`.

- 아이폰 사파리에서 열고 **공유 → 홈 화면에 추가**로 앱처럼 사용
- 화면을 열 때마다 `./data.json?t=…` 를 새로 받아 그립니다(캐시 무시). 네트워크 실패 시 `index.html` 안의 내장 fallback 데이터로 그대로 동작합니다.
- 390px 1열 기준. 다크/라이트 모드 모두 지원.

## 화면 구성 (위 → 아래)

1. **헤더** — 오늘 날짜 배지 · 날씨(Open-Meteo 대구, 탭하면 새로고침)
2. **브리핑 배너** — `briefing` + `updated_at`, ↻ 버튼으로 즉시 재동기화
3. **🔴 빨간불 미결 안건함 (돈·기한 중심)** — `urgent_inbox`
   - 상단 `확인 대기 N건` 뱃지(모두 처리하면 초록 `모두 확인 완료`)
   - 긴급도 `red > amber > blue > green` 순 정렬, 기본 3건만 보이고 **[나머지 N건 더 보기]** 로 아코디언 확장
   - 행을 탭하면 오늘 확인 처리(흐려지고 줄 그어짐) → 뱃지 숫자가 즉시 줄어듦. 다시 탭하면 되돌아옴
4. **📌 오늘의 발행 미션** — 진행률 · [문안 복사] · [앱 열기 ↗] · 모두 완료 시 축하
5. **🧵 스레드 소통 10초 컷** — 카드 2개씩 보기
   - 헤더 `N / 6 완료` 카운트, 툴바 `미완료 N건` 표시
   - 카드마다 **[📋 답글 복사 + 열기]**(클립보드 복사 + 토스트 + 원글 새 탭)와 **[복사만]**
   - 복사/열기 또는 체크를 누르면 카드가 부드럽게 접히고 다음 미완료 글이 위로 올라옴(날짜별 localStorage)
   - **[다음 2개 ▸]** 로 미완료 글을 2개씩 넘겨 봄(끝에서 처음으로 순환)
   - **[모두 다시 보기]** 로 6건 전체 펼침(접힌 카드 되돌리기, 완료 카드도 여기서 해제 가능) ↔ **[2개씩 보기]**
   - 6건 모두 확인 시 `준비된 6건을 모두 확인했어요` + **[새 글 요청 복사]** + **[처음으로]**
6. **🍳 오늘의 10분 식단 + 🛒 퇴근길 장보기** — 장보기 한 줄 배너를 크게, 그 아래 메뉴명·`prep_time` 배지, 탭하면 3줄 원팬 레시피 아코디언
7. **📅 주간 타임라인 & 현황판** — `timeline` 을 가로 스크롤 칩으로(오늘/내일/D-N 배지, 가장 가까운 일정 강조), 아래에 `status_board`(진행률 바·색 배지)
8. **⏱️ 집중 타이머** — 25/10/5분, 종료 시 Web Audio 차임
9. **🛠️ 작업실 바로가기** — 2×2 그리드

## data.json 계약 (매일 자동 갱신용)

```json
{
  "date_label": "11월 16일 월요일",
  "updated_at": "23:20 기준",
  "briefing": "한 줄 브리핑 문장",
  "urgent_inbox": [
    { "id": "u1", "title": "모모상점 치이카와 C 품절", "tag": "품절 1건", "urgency": "red|amber|blue|green" }
  ],
  "timeline": [
    { "id": "t1", "date": "11/18 (수)", "time": "07:00", "title": "🪷 마음의바다 수능 2차 연등" }
  ],
  "missions": [
    { "id": "m1", "title": "🧵 스레드 점심 공감", "time": "12:00",
      "app_label": "스레드", "app_url": "https://www.threads.com/", "copy_text": "복사할 문안" }
  ],
  "threads_replies": [
    { "id": "tr1", "topic": "인사·마음챙김", "url": "https://www.threads.com/@…/post/…",
      "reply_text": "붙여넣을 답글 문안" }
  ],
  "dinner": {
    "menu": "원팬 참치김치 팽이볶음밥 (7호)",
    "prep_time": "10분 컷",
    "shopping_item": "팽이버섯 1봉",
    "shopping_tip": "오늘 퇴근길엔 팽이버섯 1봉만 사 오세요",
    "steps": ["1단계", "2단계", "3단계"]
  },
  "status_board": [
    { "label": "🪷 연꽃세상 수익창출", "value": "1,887 / 4,000h", "progress": 47 },
    { "label": "🛒 모모상점 재고", "value": "품절 1건 확인", "tone": "red" }
  ],
  "checks":   [ { "id": "c1", "emoji": "🛒", "label": "항목", "tag": "상태", "tone": "red|amber|green|blue" } ],
  "shortcuts":[ { "id": "s1", "label": "💬 슬랙", "url": "https://…" } ]
}
```

- **`urgent_inbox`** — 빨간불 미결함의 원본. `urgency` 가 좌측 색 띠와 정렬 기준입니다. `tag` 는 상태 라벨(없으면 숨김). 항목이 없으면 카드가 숨겨집니다.
- **`timeline`** — `date` 는 `M/D` 형식이면 오늘/내일/D-N 배지가 자동 계산됩니다(연도 없는 표기 전제, 연말 넘어가면 자동으로 다음 해로 보정). 4~6건 권장, 6건을 넘으면 가로 스크롤로 밀립니다.
- **`checks`** (하위 호환) — 남아 있으면 미결함 목록 **아래에 이어서** 표시되고 대기 건수에 함께 잡힙니다. 새 항목은 `urgent_inbox` 에 넣는 것이 원칙입니다.
- **`missions`** 가 미션 목록ㆍ진행률 기준입니다. `id` 는 체크 상태 저장 키이므로 회차가 바뀌어도 되도록 같은 의미면 같은 id를 쓰고, 새 미션이면 새 id를 씁니다. `copy_text` 가 비어 있으면 [문안 복사] 가 숨겨집니다.
- **`threads_replies`** — 매일 11:50·20:50 정기 루틴이 **최신 독자층 글 6선으로 통째로 교체**합니다(계약 유지: `id` 는 `tr1`~`tr6`, 화면에는 `topic` 만 보이고 핸들은 `url` 로만 연결).
  - 6선의 `url` 구성이 바뀌면 앱이 이를 감지해 그날의 답글 완료 체크를 새 세트로 넘기지 않고 자동 초기화합니다(이전 글에 단 체크가 새 글에 붙는 것을 막음).
- **`dinner.shopping_item`** — 장보기 배너의 큰 한 줄(예: `팽이버섯 1봉`). 없으면 `shopping_tip` 을 그대로 배너에 씁니다. **`shopping_tip`** 은 배너 아래 작은 안내문. 둘 다 없으면 배너가 숨겨집니다.
- **`status_board`** — `progress`(0~100)가 있는 행만 진행률 바, 없는 행은 `tone` 색 배지.
- **`date_label`** 은 오늘 날짜와 일치할 때만 배지에 쓰이고, 아니면 실제 오늘 날짜를 계산해 표시합니다.

## 저장 키 (브라우저 localStorage)

`today-board.v1` 하나에 날짜 기준으로 저장되고, 날짜가 바뀌면 자동 초기화됩니다.

| 키 | 내용 |
|---|---|
| `done` | 미션 체크 (`m1`…) |
| `inbox` | 미결함 확인 체크 (`u:u1`, `c:c1`) |
| `replies` | 스레드 답글 완료 |
| `replyOffset` / `replyMode` | 2개씩 보기 위치 / 전체 펼침 여부 |
| `replySig` | 현재 6선의 지문(세트 교체 감지용) |
| `timerEnded` | 오늘 집중 타이머 완료 횟수 |

## 프라이버시

공개 저장소입니다. 제3자 실명·연락처·상세 주소·계정 핸들·민감 사업 정보는 넣지 않습니다. 미션 문안은 본인 발행 원고만 담습니다.

예외 하나: `threads_replies[].url` 은 답글을 달 원글의 공개 링크라서 경로에 원작성자 핸들이 들어갑니다. 화면에는 `topic` 문구만 보이고 핸들은 표시하지 않으며, 이 링크가 유일하게 핸들이 남는 자리입니다.
